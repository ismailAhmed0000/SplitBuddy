# SplitBuddy — Web App

The website client for SplitBuddy: upload a receipt, split it with your buddies, and settle up. Talks to the Laravel API in `../backend-api`.

## Stack

- **React 19** + **TypeScript**, built with **Vite**
- **TanStack Router** — file-based routing, routes live in `src/routes/` and map directly to URLs (e.g. `src/routes/_authenticated/groups/$groupId.tsx` → `/groups/:groupId`). The route tree (`src/routeTree.gen.ts`) is auto-generated by `@tanstack/router-plugin`'s Vite plugin — never hand-edit it, it regenerates on `dev`/`build`.
- **TanStack Query** — all server state and data fetching. No Redux/Zustand/global client store — everything that isn't local component state lives in the Query cache. One file per domain in `src/lib/` (`groups.ts`, `bills.ts`, `settlements.ts`, `users.ts`, `auth.ts`, …), each exporting typed hooks (`useGroup`, `useCreateSettlement`, etc.) and a `*Keys` object for cache invalidation.
- **Axios** — HTTP client (`src/lib/api.ts`). A request interceptor attaches the bearer token from `localStorage`; `parseApiError()` unwraps Laravel's `{ message, errors }` validation body into a top-level message plus per-field errors.
- **Tailwind CSS v4** — utility-first styling, no component library. Hand-built primitives live in `src/components/` (`TextField`, `Button`-equivalents inline, `CollectorBadge`/`PaidStamp` SVG seals, etc.).
- **oxlint** — linting (`npm run lint`), not ESLint.

## Auth & state

- No global client-state library. Session token lives in `localStorage` (`src/lib/api.ts`); the current user is just a TanStack Query (`useCurrentUser`), not duplicated into a store.
- Server data flows entirely through Query — mutations call `queryClient.invalidateQueries(...)` (or `setQueryData` for the auth user after a profile edit) rather than manually syncing local state.

## API conventions this client assumes

- Every endpoint wraps its payload as `{ data: ... }` — hooks unwrap this in their `queryFn`/`mutationFn`.
- 422 validation errors come back as `{ message, errors: { field: string[] } }` — always route mutation errors through `parseApiError()`.
- Auth is a bearer token (Laravel Sanctum) attached via the Axios interceptor, not cookies/sessions.

## Getting started

```bash
npm install
cp .env.example .env   # set VITE_API_URL to the backend's URL
npm run dev
```

`VITE_API_URL` must point at a running `backend-api` instance (see that project's README) — local dev typically uses `http://localhost:8000/api` or whatever port the Laravel dev server is on.

## Scripts

```bash
npm run dev       # Vite dev server with HMR
npm run build      # tsc -b && vite build — type-checks via project references, then bundles
npm run preview    # preview the production build locally
npm run lint       # oxlint
```

**Note:** `npm run build` runs `tsc -b` (composite/project-reference type-checking) before bundling — this can catch type errors that a plain `tsc --noEmit` misses, since it isn't wired into the same project-reference graph. When in doubt, trust `npm run build` over an ad-hoc `tsc --noEmit`.
